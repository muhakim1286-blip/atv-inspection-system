## 🚀 STEP-BY-STEP DEPLOYMENT

### STEP 1: Deploy Staff Form to Vercel (5 minutes)

**Prerequisites:**
- GitHub account (free)
- Vercel account (free, auto-connects to GitHub)

**Instructions:**

1. **Create GitHub repo:**
   - Go to: https://github.com/new
   - Name: `atv-inspection-form`
   - Make it Public
   - Create repository

2. **Upload form file:**
   - Clone the repo to your computer
   - Copy `GY6-Daily-Routine-Check-v2.html` into it
   - Push to GitHub:
   ```bash
   git add GY6-Daily-Routine-Check-v2.html
   git commit -m "Add inspection form"
   git push
   ```

3. **Deploy to Vercel:**
   - Go to: https://vercel.com
   - Sign up with GitHub
   - Click "New Project"
   - Select your `atv-inspection-form` repo
   - Click "Deploy"
   - Wait 1 minute...
   - ✅ You now have a live URL!

**Example URL:**
```
https://atv-inspection-form.vercel.app/GY6-Daily-Routine-Check-v2.html
```

## 🚨 TROUBLESHOOTING

### Link doesn't work
- Wait 2-3 minutes after deploying
- Refresh the page
- Check Vercel deployment status

### Form won't submit
- Check browser console (F12)
- Verify all fields are filled
- Ensure pre-ride photo is taken
- Try different browser

### Photos not showing
- This is normal for demo
- In production: will upload to server
- For now: click "Take Photo" and it logs timestamp

### Staff can't access on mobile
- Verify link is correct
- Check internet connection
- Try in different browser
- Make sure form is public (not private)
